Weighted grids and cost-based paths.

Heuristic-guided search with Manhattan distance.

Animate each step of the search.

## 🔧 Troubleshooting

| **Infinite loop** | Mark visited nodes |
| **Slow BFS** | Use a deque |

| **DFS stack overflow** | Use iterative DFS |
| **Animation lag** | Reduce frame rate |
